Steam Web API key
How do I get this?
  1. Go to steamcommunity.com/dev/apikey and sign in.
  2. In the Domain Name box, type anything, e.g. localhost. It doesn't need to be a real website.
  3. Tick the agreement and click Register.
  4. Copy the Key it shows you (a 32-character code) and paste it above.

Keep this private, it's like a password for reading your library.

64-bit Steam ID
How do I find this?

Easiest option: let the app find it. Type your Steam profile name or paste your profile URL below and click Look up; the app fills in your ID for you.

Prefer to find it in Steam? No website needed:

  1. In the Steam app, click your name (top-right) → View my profile.
  2. Right-click anywhere on the profile page → Copy Page URL.
  3. If it looks like steamcommunity.com/profiles/7656119…, that 17-digit number is your ID. Paste the whole URL above and we'll pull it out.

A 64-bit Steam ID is 17 digits and starts with 76561. Third-party finders (e.g. steamid.io) also work but are sometimes region-blocked.
